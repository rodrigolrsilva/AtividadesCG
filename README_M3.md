# Hello3D M3 - Computacao Grafica

Aluno: Rodrigo Luis Rodrigues da Silva

Extensao do visualizador 3D do Modulo 3: leitura de arquivo .OBJ com coordenadas de textura, leitura do material no .MTL e renderizacao texturizada.

## Como compilar e executar

```bash
mkdir build && cd build
cmake ..
cmake --build .
./Hello3D_M3
```

## Controles

| Tecla | Acao |
|---|---|
| X / Y / Z | Liga/desliga rotacao no eixo correspondente |
| A / D | Translada em X |
| W / S | Translada em Z |
| I / J | Translada em Y |
| - / = | Diminui/aumenta escala |
| ESC | Fecha |
