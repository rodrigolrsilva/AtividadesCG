# Hello3D M4 - Computacao Grafica

Aluno: Rodrigo Luis Rodrigues da Silva

Desafio do Modulo 4: modelo de iluminacao de Phong com leitura de normais do OBJ e coeficientes Ka/Kd/Ks/Ns do MTL. Renderiza 3 instancias do modelo com iluminacao ambiente, difusa e especular modulada pela textura.

## Como compilar e executar

```bash
mkdir build && cd build
cmake ..
cmake --build .
./Hello3D_M4
```

## Controles

| Tecla | Acao |
|---|---|
| X / Y / Z | Liga/desliga rotacao no eixo correspondente |
| A / D | Translada em X |
| W / S | Translada em Z |
| I / J | Translada em Y |
| - / = | Diminui/aumenta escala |
| ESC | Fecha |
