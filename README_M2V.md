# Vivencial M2 - Computação Gráfica

**Aluno:** Rodrigo Luís Rodrigues da Silva

Extensão do exercício do Módulo 2: exibe dois modelos 3D (.OBJ) na cena com seleção e transformações individuais por teclado.

## Como compilar e executar

```bash
mkdir build && cd build
cmake ..
cmake --build .
./Hello3D_M2V
```

## Controles

| Tecla | Ação |
|---|---|
| TAB | Seleciona o próximo objeto |
| X / Y / Z | Liga/desliga rotação no eixo correspondente |
| ← → | Translada em X |
| ↑ ↓ | Translada em Z |
| I / J | Translada em Y |
| - / = | Diminui/aumenta escala |
| ESC | Fecha |
