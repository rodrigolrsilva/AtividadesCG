# Hello3D M4V - Computacao Grafica

Aluno: Rodrigo Luis Rodrigues da Silva

Vivencial do Modulo 4: modelo de Phong com 3 luzes pontuais posicionadas automaticamente pela tecnica de iluminacao de 3 pontos, a partir da posicao e escala do objeto. Implementa fator de atenuacao na parcela difusa.

## Como compilar e executar

```bash
mkdir build && cd build
cmake ..
cmake --build .
./Hello3D_M4V
```

## Controles

| Tecla | Acao |
|---|---|
| X / Y / Z | Liga/desliga rotacao no eixo correspondente |
| A / D | Translada em X |
| W / S | Translada em Z |
| I / J | Translada em Y |
| - / = | Diminui/aumenta escala |
| 1 / 2 / 3 | Liga/desliga luz principal / preenchimento / fundo |
| ESC | Fecha |
